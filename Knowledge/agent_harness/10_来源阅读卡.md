> 更新于 2026-11-14。缺口编号对应 [Review 01](../../Review/agent_harness/01_差距优先级与时间估算.md)。

## 阅读状态的含义

| 标记 | 含义 |
|---|---|
| **原文核对** | 2026-11-14 下载 arXiv PDF 或网页原文，转成文本后逐条核对所列数字与位置（不经摘要工具） |
| **直接读正文** | 读了 PDF 正文文本，但并非每个数字都逐条核对 |
| **二手摘要** | 由摘要式抓取工具返回的内容，可能有遗漏或改写；数字未经原文核对 |
| **仅摘要** | 只读了 arXiv 摘要或博客摘要 |
| **代码已读** | 在固定 commit 上阅读了所列文件与函数，**未运行** |
| **代码已运行** | 在本地实际执行过 |

只有“原文核对”的数字适合在面试中直接引用。其他状态的数字放在本页末尾的待核查区。
